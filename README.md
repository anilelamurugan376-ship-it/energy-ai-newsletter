# 能源 × AI 每日简报 Skill

## 简报定位

- **受众**：加油站/充电站老板、运营负责人、营销人员
- **视角**：实用、有判断、有温度，不做平铺直叙
- **语言**：中文为主，数据可保留英文原文
- **发布节奏**：每个工作日一期，期号连续累计

---

## 核心工作流

```
1. 推荐3个选题方向（含说明）
2. 用户选择方向（可合并）
3. 搜索最新素材（web_search × 2–3次）
4. 生成完整简报（HTML Widget 可视化）
5. 提供"复制纯文字版"/"生成朋友圈文案"/"下期选题"快捷按钮
```

---

## 第一步：推荐选题方向

每次推荐 **3个方向**，结构如下：

```
**方向 A · [主题标题]**
[2–3句说明：聚焦什么问题、适合哪类受众、与前几期的关系]

**方向 B · [主题标题]**
[同上]

**方向 C · [主题标题]**
[同上]

---
[1–2句推荐语，说明本期最适合选哪个方向及原因]
```

### 选题维度轮换原则

避免连续两期使用同一维度，优先从以下维度中选取尚未覆盖的：

| 维度 | 关键词 |
|------|--------|
| 宏观运营 | 行业全景、政策解读、市场数据 |
| 选址扩张 | AI选址、布局策略、数据工具 |
| 用户营销 | 会员运营、留存、个性化推荐 |
| 改造案例 | 真实案例、转型实录、人物故事 |
| 海外视角 | 欧美巨头、跨国对比、前瞻趋势 |
| 人物视角 | 一线从业者、站长、投资人心声 |
| 技术前沿 | V2G、预测维护、AI安全、储能调度 |
| 安全合规 | 法规、安全生产、AI监控 |

---

## 第二步：搜索素材

用户确认选题后，执行 **2–3次 web_search**，关键词策略：

```
搜索1：[主题] + AI + [年份] （中文）
搜索2：[主题英文关键词] + technology/AI + 2025/2026 （英文）
搜索3（可选）：具体公司/案例名称 + 数据/结果
```

搜集目标：
- 3–5条可用新闻/案例/数据
- 每条需含：事件描述 + 具体数据 + 对受众的意义

---

## 第三步：生成简报 HTML Widget

调用 `visualize:show_widget` 生成完整简报，**必须包含以下所有板块**：

### 固定板块结构

```
[简报头部]        ← 期号、标题、副标题、日期、受众标注
[本期核心数据]    ← 3个关键数字，stat-grid 布局
[本期焦点]        ← 3–5条新闻卡片（见新闻卡片规范）
[本周一图]        ← SVG 可视化（见图表规范）
[本周工具推荐]    ← 2–3个工具卡片
[编辑观点]        ← 1段强判断、有立场的总结
[页脚 + 快捷按钮] ← 复制纯文字版 / 朋友圈文案 / 下期选题
```

### 新闻卡片规范

每条新闻包含：
- 序号圆圈 + 分类标签（颜色见下方色系）
- 标题（14px, font-weight:500）
- 正文（13px, line-height:1.65, 约100–150字）
- 可选：对受众的**行动建议**（斜体或小字）

分类标签色系：
```
行业趋势   → #E6F1FB / #0C447C（蓝）
学术研究   → #FAEEDA / #633806（琥珀）
产品动态   → #EEEDFE / #3C3489（紫）
运营策略   → #E6F1FB / #0C447C（蓝）
安全警示   → #FCEBEB / #791F1F（红）
国内案例   → #EAF3DE / #27500A（绿）
海外视角   → #E1F5EE / #0D6957（青）
人物故事   → #FAEEDA / #633806（琥珀）
```

### 本周一图规范

根据选题类型选择图表形式：

| 选题类型 | 推荐图表 |
|----------|----------|
| 对比/竞争 | 两栏对比表格（SVG table） |
| 流程/步骤 | 横向箭头流程图 |
| 数据/趋势 | 五维/多维放射图或柱状示意 |
| 路径/选择 | 三栏路径对比卡片 |
| 人物/案例 | 时间轴（timeline） |
| 系统/架构 | 中心辐射图（hub-spoke） |

图表要求：
- 纯 SVG，无外部依赖
- viewBox 宽度 620，高度 130–200
- 使用与简报主色调一致的配色
- 图表下方附 1 行说明文字（12px, 居中, 灰色）

### 配色主题

根据选题氛围选择头部配色：

```
深蓝（默认/科技）   → #042C53
深绿（转型/案例）   → #173404
深靛（人物/故事）   → #1a1a2e → #0f3460
渐变蓝绿（综合）    → #042C53 → #0C5C2A
```

### CSS 变量规范

所有样式使用 CSS 变量以支持明暗主题：
```css
var(--color-text-primary)
var(--color-text-secondary)
var(--color-background-primary)
var(--color-background-secondary)
var(--color-border-tertiary)
var(--font-sans)
var(--border-radius-lg)
var(--border-radius-md)
```

## 第四步：页脚快捷按钮

页脚固定包含 3 个按钮，使用 `sendPrompt()` 触发：

```javascript
onclick="sendPrompt('帮我把第X期邮件正文整理成纯文字格式')"
onclick="sendPrompt('根据第X期内容，帮我生成一条适合发朋友圈的推广文案')"
onclick="sendPrompt('帮我生成第Y期选题方向')"
```

## 朋友圈文案规范

当用户请求"朋友圈文案"时，输出：
- 长度：150–200字
- 结构：1句钩子 + 3条核心洞察（带emoji）+ 1句行动召唤
- 风格：有判断、略带紧迫感，不卖弄技术术语
- 结尾附：#能源AI #充电站 #加油站转型

## 期号管理

- 若无上下文，询问用户当前期号
- 页脚、按钮、文字版均需保持期号一致
